# وضعیت بررسی نسخه ۰.۱

تاریخ: ۲۰۲۶/۱۱/۱۳

## بررسی انجام‌شده

`npm test`: پنج تست موفق. هر ۲۴ ترکیب انتخاب، با ذخیره و بازیابی در تک‌تک صحنه‌ها تا پایان پیمایش شد. هر دو پایان قابل دستیابی‌اند. مدرک تکراری یادداشت تکراری نمی‌سازد. قبل از خواندن همه مدارک، خروج از بررسی مسدود است. معمای غلط حالت بازی را خراب نمی‌کند. ذخیره ناسازگار و داده آماری نامعتبر رد می‌شود. انتخاب نخست مسیر و دفتر را تغییر می‌دهد.

`npm run check`: بررسی نحو چهار فایل جاوااسکریپت موفق بود.

`npm run build`: فایل مستقل `release/sangarsazan.html` ساخته شد. اجرای آن به شبکه یا بسته اضافی نیاز ندارد.

## محدودیت بررسی

سرور محلی اجرا شد، اما درخواست HTTP محیط اجرا با محدودیت سوکت روبه‌رو شد و مرورگر آزمایش نیز در اتصال به localhost به پایان مهلت رسید. بنابراین ادعای تست بصری، پیمایش عملی رابط، تأیید اندازه موبایل، یا تست صوت در این نسخه نداریم. تست‌های بالا مربوط به موتور داستان هستند.

## آزمون دستی بعدی

فایل HTML مستقل را در Chrome و مرورگر گوشی باز کنید. شروع، دو انتخاب نخست، خواندن هر سه مدرک، فعال‌شدن دکمه بازگشت، نقشه و دفتر را بررسی کنید. معما را یک‌بار غلط و سپس درست بچینید. پایان بازبینی و پایان تحویل را جدا امتحان کنید. وسط کار صفحه را ببندید و دوباره «ادامه مأموریت» بزنید. فایل ذخیره دریافت و دوباره وارد کنید. عرض ۳۶۰ پیکسل، کلید Tab و Escape پنجره‌ها، خوانایی متن فارسی و روشن/خاموش‌کردن صدا را بررسی کنید.

خروجی تک‌فایلی از همان منبع ساخته شده است؛ با هر تغییر کد، `npm run build` دوباره اجرا شود.
