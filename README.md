# سنگرسازان

هسته بازی روایی دوبعدی «جهادگران»، با مأموریت نمونه «راهی میان آب» در فضای عملیات خیبر. نسخه ۰.۱، قابل بازی در مرورگر گوشی و کامپیوتر.

## اجرا

فایل `release/sangarsazan.html` را دانلود و با مرورگر باز کنید. همه اجزای بازی داخل همان فایل است و به اینترنت نیاز ندارد. ذخیره خودکار وابسته به اجازه مرورگر است؛ برای جابه‌جایی بین دستگاه‌ها از «دریافت فایل ذخیره» و «ورود فایل ذخیره» استفاده کنید.

برای توسعه با Node.js نسخه ۲۰ یا بالاتر:

```sh
npm start
```

آدرس: http://localhost:4173 . نصب وابستگی لازم نیست.

```sh
npm test
npm run check
npm run build
```

## امکانات فعلی

گفت‌وگو با تصویر شخصیت در سمت راست یا چپ، شاخه‌های انتخاب با پیامد فوری، دفتر مأموریت، خواندن مدارک، نقشه شماتیک قابل بررسی، معمای چهارکارتی، دو پایان، مرور دیالوگ، راهنمای هر بخش، ذخیره خودکار و خروجی/ورودی JSON. صدای محیط با انتخاب بازیکن روشن می‌شود. راه اشتباه قابل اصلاح است و بن‌بست ایجاد نمی‌کند.

کنترل: لمس یا کلیک؛ در صحنه‌های گفت‌وگو کلید Enter یا Space نیز ادامه می‌دهد. تمام کنترل‌ها با Tab قابل دسترسی‌اند.

## ساختار و افزودن عملیات

`dist/engine.js` منطق مستقل از نمایش است. `dist/chapter.js` داده‌های فصل، شخصیت‌ها، شاخه‌ها و یادداشت‌ها را دارد. `dist/app.js` رابط و ذخیره محلی است. `dist/art.js` طرح‌های SVG موقت و `dist/style.css` طراحی واکنش‌گرا را نگه می‌دارند.

نوع صحنه‌ها: `dialogue`، `choice`، `inspect`، `puzzle` و `ending`. هر فصل `id`، `start` و `nodes` مستقل دارد. برای اضافه کردن فصل، داده جدا تعریف و در CHAPTERS ثبت کنید؛ سپس انتخاب فصل و ذخیره‌های چندفصلی را در رابط فعال کنید. در این نسخه تنها یک فصل قابل بازی است و انتخابگر عملیات بعدی عمداً محتوای ساختگی ندارد.

یک گزینه با `requires` به پرچم‌ها وابسته می‌شود؛ `effects` می‌تواند پرچم، یادداشت یا آمار را تغییر دهد. موتور، مقصد شاخه‌ها و نسخه ذخیره را بررسی می‌کند. `tests/engine.test.js` همه ۲۴ ترکیب انتخاب را تا پایان، همراه با ذخیره/بازیابی هر صحنه می‌آزماید.

## مرز نسخه نمونه

این نسخه هسته قابل بازی است، نه فصل کامل ۲۰ تا ۳۰ دقیقه‌ای. تصاویر و چهره‌ها طرح موقت‌اند؛ چهره منتسب به مهندس، پرتره مستند نیست. نقش بازیکن و یونس خیالی‌اند. گفت‌وگوهای مهندس پورشریفی بازآفرینی داستانی‌اند و نقل‌قول واقعی معرفی نمی‌شوند. نتیجه تاریخی عملیات با انتخاب‌ها تغییر نمی‌کند.

فایل پژوهشی «خیبر» متین مبنای موضوعی است. ناسازگاری‌های آن درباره تاریخ‌ها، وقایع پس از عملیات، آمار و انتساب‌ها در این نمونه به‌عنوان واقعیت تکرار نشده‌اند و پیش از فصل نهایی به بررسی منابع دست‌اول نیاز دارند. معمای کارگاهی یک فعالیت نمادین است، نه راهنمای مهندسی پل.

بسته APK، پرداخت درون‌برنامه‌ای، گرافیک نهایی و دوبله هنوز ساخته نشده‌اند. بازی API، ورود کاربر، ردیاب یا سرور داده ندارد. ذخیره‌ها در دستگاه بازیکن می‌مانند.
